# גזור / הדבק — Sticker Lab

פרויקט עצמאי של Bar Klein. העלאת תמונה, זיהוי אובייקטים וחיתוך אוטומטי למדבקות שקופות, וציור בקנבס p5.js באמצעות מברשת אקראית. אינו משנה את פרויקט Wild Garden או את הגשתו לקורס.

## הפעלה
יש להגיש את התיקייה באמצעות שרת HTTP או GitHub Pages (לא file://). פתיחת index.html טוענת p5.js 2.3.3. החילוץ טוען Transformers.js 3.8.1 ואת המודלים רק לאחר לחיצה על כפתור החילוץ. משתמשים ב־Worker כדי להשאיר את הממשק זמין. דפדפן Chrome/Edge עדכני מומלץ; החילוץ יכול להימשך דקות במחשב חלש.

## עיבוד
- DETR ResNet-50: זיהוי עד 16 אובייקטים בעלי ביטחון של לפחות 0.55. הקטגוריות מוגבלות לאלו שנלמדו במודל; אין הבטחה לזיהוי כל דבר, ובפרט סל כדורסל אינו קטגוריה נפרדת.
- SlimSAM: תיבות הזיהוי מתורגמות אוטומטית לנקודת קדמה במרכז האובייקט וארבע נקודות רקע מחוץ לתיבה. נבחרת המסכה בעלת ציון איכות החיתוך הגבוה ביותר. תכונות התמונה מחושבות פעם אחת ומשמשות לכל המדבקות.
- התמונה מוגבלת לצלע של 1024 פיקסלים לעיבוד. כל העיבוד מקומי בדפדפן. אין העלאת התמונה לשרת. נדרש אינטרנט להורדת קוד, גופנים ומודלים; דוגמת החתולים נטענת רק בעקבות לחיצה.
- כל הטבעה שומרת גודל, סיבוב, גוון, שקיפות, מיקום ומדבקה שנבחרו בזמן ההטבעה. שינוי מכוונים לא משנה את הקומפוזיציה הקיימת. ריווח המברשת תלוי במרחק התנועה, לא בקצב אירועי העכבר.
- ביטול/שוב לפי משיכת מכחול, ניקוי בר־ביטול, שינוי רקע, ושמירת PNG בגודל 1200×800. היצירה אינה נשמרת לאחר רענון; יש לייצא אותה.
